# Analysis

This folder contains the analytical components of the case study.

## Files

### `01_hta_context.md`

Introduction to the German HTA framework, including:

- §35a SGB V
- AMNOG
- IQWiG
- G-BA

### `02_pico_and_zvt.md`

Defines the PICO framework and the Zweckmäßige Vergleichstherapie (ZVT) for the case.

### `03_evidence_mapping.md`

Maps the CLARITY AD evidence to the specific German HTA research questions.

### `04_critical_appraisal.md`

Critically evaluates:

- comparator alignment
- population relevance
- statistical evidence
- confidence intervals
- risk of bias
- safety
- evidence gaps
- benefit-harm balance

### `05_hta_evidence_summary.md`

Provides a consolidated evidence summary connecting the PICO, ZVT, clinical evidence and IQWiG conclusion.
