# Data

## Evidence Table

`evidence_table.csv` contains a structured extraction of selected evidence and effect estimates relevant to the IQWiG A25-111 assessment.

The table is intended to support:

- evidence mapping
- statistical interpretation
- comparison of outcomes
- identification of benefit and harm signals

## Important

The data are extracted from publicly available IQWiG assessment documentation.

The table is a portfolio-oriented analytical extraction and should not be interpreted as an official IQWiG dataset.
